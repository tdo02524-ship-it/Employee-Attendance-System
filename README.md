# Employee-Timekeeping-System

Employee timekeeping and management system built from scratch as a course project.

## Demo
[Watch the demo video](https://youtu.be/V4_Ol5M3ZJo)
![UI](images/ui.png)

## Features
- Employee profiles, shift assignment, clock-in/out history
- Automated payroll (daily, weekly, monthly, yearly) with individual bonus/penalty rules
- Performance analysis, top-employee ranking, automatic reports
- SQL Server database for synchronized and secure timekeeping records

## Technologies
- C#, SQL Server, SQL
- Visual Studio, SQL Server Management Studio

## How to run
1. Restore the database from `database/` into SQL Server.
2. Update the connection string in the config file.
3. Open the solution in Visual Studio and run.
